# DSCI 552 Homework 7

This repository contains my solutions for Homework 7 of DSCI 552: Machine Learning for Data Science.

## Repository Structure

- `data/` - Anuran Calls MFCC dataset
- `notebook/` - Jupyter Notebook containing the code, results, plots, and written answers
- `requirements.txt` - Python packages required to run the notebook


## Running the Notebook

1. Clone this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Open the notebook inside the `notebook` folder.
4. Run all cells in order.

The notebook uses relative file paths, so the original directory structure should be kept unchanged.
